CoolPhoto portable mode

While this file sits next to coolphoto.exe, CoolPhoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the CoolPhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move CoolPhoto with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\CoolPhoto) instead.
If CoolPhotoData can't be written (for example on a read-only drive), CoolPhoto says so and
uses %APPDATA%\CoolPhoto instead.
